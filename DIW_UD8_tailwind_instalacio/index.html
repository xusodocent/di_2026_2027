    En DAM, Tailwind és un mitjà per construir interfícies coherents i adaptables (RA4.c–h). La generació de CSS no equival al codi d’interfície generat per un editor visual de RA1: aquest resultat requereix una activitat específica. Consulta el mapa de continguts i RA de DAM.

    Tailwind CSS: instal·lació i configuració

    Aquesta unitat utilitza Tailwind CSS 4. Les classes utilitàries apliquen regles CSS des de l’HTML; no són atributs style ni eliminen la necessitat de comprendre CSS.

    Prova ràpida amb Play CDN

    Per a exercicis breus pots usar el compilador de navegador. Necessita connexió i està destinat a desenvolupament; per publicar el projecte genera un CSS estàtic.

<head>

  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Prova de Tailwind</title>
  <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
</head>
<body class="bg-gray-100 p-6">
  <h1 class="text-3xl font-bold text-blue-700">Hola, Tailwind!</h1>
  <p class="mt-4">Una interfície construïda amb classes utilitàries.</p>
</body>
</html>

    Amb el tema per defecte, p-6 equival a 1.5rem i text-3xl a 1.875rem; «3xl» no significa multiplicar la lletra per tres. Les mesures i colors es poden personalitzar.

    Instal·lació local amb CLI

    Amb Node.js LTS i npm disponibles, crea la carpeta del projecte:

    Bash
    1
2
3
4
    mkdir meu-projecte-tailwind
cd meu-projecte-tailwind
npm init -y
npm install -D tailwindcss@4 @tailwindcss/cli@4

    Crea src/input.css:

    CSS
    1
    @import "tailwindcss";

    Crea src/index.html amb l’HTML anterior, substituint el <script> del CDN per:

    HTML
    1
    <link rel="stylesheet" href="./output.css">

    Des de l’arrel del projecte executa:

    Bash
    1
    npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

    Obri src/index.html al navegador. La CLI recompila quan guardes els fitxers; para-la amb Ctrl+C. Per generar el CSS final una sola vegada:

    Bash
    1
    npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --minify

    Conserva package.json i package-lock.json; npm ci permet reinstal·lar les versions registrades. Publica l’HTML i el CSS generat, sense necessitar Node.js al navegador.

    Configuració en CSS

    En v4 pots ampliar el tema en el fitxer d’entrada:

    CSS
    1
2
3
4
5
    @import "tailwindcss";

@theme {
  --color-marca: #302052;
}

    Això permet usar bg-marca o text-marca. La detecció de classes és automàtica en els fitxers de treball habituals; consulta detecció de classes per a rutes addicionals.

    Les instruccions npx tailwindcss init, @tailwind base/components/utilities i la configuració JavaScript amb content corresponen a versions anteriors. No les combines amb aquesta instal·lació v4. La CLI actual és un paquet separat i aquesta via no requereix configurar PostCSS ni Autoprefixer.
